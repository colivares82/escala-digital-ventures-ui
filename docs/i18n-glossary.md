## 6. Editorial guardrails (apply in all languages)

- No physical/street address.
- No former-employer names (anonymized experience formula only).
- IP and source code belong to Escala — never state the client owns the code.
- `colivares.com` appears as plain text only (not a link).
- No "ruso" / "russian" / "rusa" in any locale.
- No medical diagnosis claims in BioZero copy (capability-framed only).
- Email `hola@escaladigitalventures.com` is the only public contact address.

---

## 7. Register notes

- **EN:** International business English. First person plural ("We automate…"). Direct, confident. No US/UK-specific idioms. No machine-literal calques from Spanish.
- **CA:** Proper Catalan orthography (·l, accents, apostrophes). First person plural ("Automatitzem…"). Same voice as ES/EN.
- **All locales:** Business-before-technology framing. Claims are recreated for punch, not translated word-for-word.
